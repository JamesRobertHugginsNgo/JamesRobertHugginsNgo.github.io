# Dark Matter

Front matter is great for including metadata in files but it only works on markdowns and with the right rendering software. I would not be able to use this on HTML, CSS, JavaScript for example.

My solution is Dark Matter, Front matter but using comments for delimiter. It can be HTML comment, C style comments or perl inline comments. Since comments are hidden from its renderer or compiler it is ignored.

With Dark Matter a mark down can perfectly render the content without the metadata. And we can add parser information to use the correct renderer for the format used. For typescript and SASS we can also use this to imbed compiler information so it provides specific instruction for this specific file. For static site generator we can also point to assents that should be carried over to the website.
