# ActivitySessions

"Let's Play" is a YouTube video where the audience watches a player plays a video game. The content is not the game itself but the play and the thoughts involved. Using the same idea for coding and we encounter a problem, "Let's Code" already exist and its about tutorials rather than following along.

ActivitySession is a new genre label for "Let's Play" for any activity. A play session should be PlaySession, a blogging session should be BlogSession and a coding session should be CodeSession.
